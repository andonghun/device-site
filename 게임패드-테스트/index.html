게임패드 테스트

게임패드를 연결하고 버튼을 하나 누르면 버튼·트리거·스틱 값이 나옵니다. 스틱에서 손을 뗀 채 3초 동안 중심에서 10% 이상 벗어나면 쏠림 의심으로 봅니다.

게임패드를 USB나 블루투스로 연결한 뒤 아무 버튼이나 한 번 누르세요. 브라우저는 버튼이 한 번 눌린 뒤에야 패드를 페이지에 보여 줍니다.

두 스틱에서 손을 뗀 채로 누르세요

아이폰 사파리와 파이어폭스는 게임패드 진동을 지원하지 않습니다.

확인하는 법

  1. 버튼을 하나씩 눌러 칠해지는지 봅니다. 트리거(LT·RT, L2·R2)는 끝까지 당겨 100% 가까이 오르는지 봅니다.
  2. 스틱을 크게 돌려 점이 원 가장자리까지 닿는지 봅니다.
  3. 두 스틱에서 손을 떼고 쏠림 재기를 누릅니다. 3초 동안 중심에서 10% 이상 벗어나면 쏠림 의심입니다. 10%는 이 사이트가 정한 값입니다.
  4. 진동 시험을 눌러 양손에서 떨림이 느껴지는지 봅니다.

쏠림이면 수리·보증

2026년 10월 30일에 각 공식 페이지 원문을 열어 확인했습니다. 제조사가 기준을 바꿀 수 있으니 출처에서 다시 확인하세요.

  • 한국닌텐도 Joy-Con 스틱·버튼 조작 문제는 한쪽 27,000원 부품 수리(양쪽 54,000원), A·B·X·Y·방향 버튼 문제는 한쪽 37,000원 새 제품 교환(양쪽 74,000원). 출처 repair.nintendo.co.kr
  • 한국닌텐도 Pro 컨트롤러 스틱·버튼 조작 문제와 배터리 교환은 39,000원 부품 수리 또는 49,000원 새 제품 교환. 출처 repair.nintendo.co.kr
  • 한국닌텐도 Joy-Con 2 스틱·버튼이 작동하지 않거나 배터리를 바꾸는 경우 1개 40,000원. Nintendo Switch 2 Pro 컨트롤러는 66,000원 교환. 출처 repair.nintendo.co.kr
  • 한국닌텐도 보증 게임기 제품 보증 기간은 구매일부터 1년. 한국에서 Joy-Con 쏠림 무상 수리를 따로 공지한 공식 페이지는 찾지 못했다. 출처 repair.nintendo.co.kr
  • 소니 플레이스테이션 컨트롤러 보증 기간은 영수증의 구매일부터 1년이고 온라인 등록 90일 추가 보증은 해당하지 않는다. 컨트롤러 수리비 표는 공개하지 않는다. 출처 playstation.com

마이크로소프트 엑스박스 컨트롤러의 한국어 보증 페이지는 찾지 못했다.

이 테스트가 못 하는 것

표준 배치로 잡히지 않는 패드는 버튼 이름 대신 번호로 나오고 번호 순서는 패드마다 다릅니다. 페이지가 패드 값을 읽어 가는 구조라 폴링레이트는 재지 않습니다. 진동은 브라우저와 패드가 둘 다 지원해야 하고 아이폰 사파리와 파이어폭스에서는 버튼이 꺼져 있습니다.

자주 묻는 질문

조이콘 스틱 쏠림 수리비는 얼마인가요?

한국닌텐도 수리 가격표(2026년 10월 30일 확인) 기준입니다. Joy-Con: 스틱·버튼 조작 문제는 한쪽 27,000원 부품 수리(양쪽 54,000원), A·B·X·Y·방향 버튼 문제는 한쪽 37,000원 새 제품 교환(양쪽 74,000원). Joy-Con 2: 스틱·버튼이 작동하지 않거나 배터리를 바꾸는 경우 1개 40,000원. Nintendo Switch 2 Pro 컨트롤러는 66,000원 교환.

듀얼센스 같은 플레이스테이션 컨트롤러 보증 기간은 얼마인가요?

소니 보증 안내(2026년 10월 30일 확인): 컨트롤러 보증 기간은 영수증의 구매일부터 1년이고 온라인 등록 90일 추가 보증은 해당하지 않는다. 컨트롤러 수리비 표는 공개하지 않는다.
